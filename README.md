# Steam Oxide

A fast, macOS-only Steam client written in Rust. Steam's look, modernised, built for the Mac,
with CrossOver support for Windows games.

Closed source. This repository only hosts downloads and the [licence](LICENSE).
Unofficial: not affiliated with or endorsed by Valve.

## Install
1. Download `Steam-Oxide.dmg` from the [latest release](../../releases/latest).
2. Open it and drag **Steam Oxide** to Applications.
3. The app is ad-hoc signed, not notarized. On first launch right-click it, choose **Open**,
   then **Open** again. Or run: `xattr -dr com.apple.quarantine "/Applications/Steam Oxide.app"`

## What is in 0.1.0
Library, store, friends, downloads, Workshop downloads, Community (Discussions, Guides,
Broadcasts, read-only), cloud saves, CrossOver for Windows games.
